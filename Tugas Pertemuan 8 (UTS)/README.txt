Cara menjalankan dengan XAMPP:
1. Ekstrak folder web_kasir_sederhana.
2. Salin folder tersebut ke C:\xampp\htdocs\
3. Jalankan Apache dari XAMPP Control Panel.
4. Buka browser dan kunjungi:
   http://localhost/web_kasir_sederhana/
5. Masukkan total belanja, misalnya 120000, lalu klik Hitung Diskon.

Catatan:
- Tidak membutuhkan database atau MySQL.
- Logika diskon berada di fungsi PHP hitungDiskon($totalBelanja).
- HTML membentuk tampilan, CSS mengatur desain, dan PHP menghitung diskon.
